## ✨ Features

- 🖤 **Ultra-Modern Dark Theme:** AMOLED / OLED display black carbon styling.
- ⚡ **3D Glowing EV Branding:** Custom high-tech electric car plugged into charging station.
- 🚗 **Vehicle Requirement Matcher:** Tata Nexon EV, MG ZS EV, Mahindra XUV400, Ola S1 Pro, Ather 450X, Commercial 3-Wheelers.
- 📍 **Pan-India Residential Stations:** 75+ Indian cities covered with real-time socket compatibility (Type-2 AC, 15A Socket, Fast AC).
- 🔐 **Mobile OTP Authentication:** Verification via mobile number and fast SMS integration.
- 🏠 **Residential Host Portal:** List private home chargers, manage bookings, and earn passive income.
- 📱 **100% Cross-Device Responsive:** Native mobile app experience on smartphones + sleek desktop frame on laptops and Mac.

---

## 🔐 Authentication & Roles

- 🚗 **EV Driver Registration:** Drivers create their account with name, email, mobile, and secure password to discover and book private charging stations.
- 🔌 **Charger Host Registration:** Residential hosts register their properties, list charging sockets, and manage driver bookings.
- 👑 **Platform Owner Administration:** Single pre-configured administrator role authenticated securely via `ADMIN_EMAIL` / `ADMIN_PASSWORD` environment variables.
