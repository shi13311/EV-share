## ✨ Features

- 🖤 **Ultra-Modern Dark Theme:** AMOLED / OLED display black carbon styling.
- ⚡ **3D Glowing EV Branding:** Custom high-tech electric car plugged into charging station.
- 🚗 **Vehicle Requirement Matcher:** Tata Nexon EV, MG ZS EV, Mahindra XUV400, Ola S1 Pro, Ather 450X, Commercial 3-Wheelers.
- 📍 **Pan-India Residential Stations:** 75+ Indian cities covered with real-time socket compatibility (Type-2 AC, 15A Socket, Fast AC).
- 🔐 **Clean Authentication System:** Dedicated landing page with EV Driver and Charger Host registration (Zero mock/demo credentials).
- 📅 **Interactive Slot Booking Modal:** Date picker, duration chips, time slots grid with collision prevention, and transparent tariff calculation.
- 🏠 **Residential Host Portal:** List private home chargers, manage bookings, and track passive earnings.
- 👑 **Platform Owner Admin Center:** Live platform statistics, user management, and station moderation.
- 📱 **100% Cross-Device Responsive:** Native mobile app experience on smartphones + sleek desktop layout on laptops.

---

## 🔐 Authentication & Roles

- 🚗 **EV Driver:** Discover residential sockets, reserve slots, generate digital QR charging passes, and manage session history.
- 🔌 **Charger Host:** List home sockets, configure custom tariffs, set availability windows, and track earnings.
- 👑 **Platform Owner Admin:** Single pre-configured administrator role authenticated securely on server.

## 🛠️ Local Development Setup

```bash
# 1. Clone repository
git clone https://github.com/shi13311/EV-share.git

# 2. Open project folder
cd EV-share

# 3. Start server
node server.js
```

Then visit **http://localhost:5000** or **http://localhost:3000** in your browser!
